# CSVデータ仕様

`data/*.csv` はすべて同じ列構成です（ステップ5で決定）。新しいカテゴリを追加する際も、この構成に従ってください。

| 列名 | 型 | 必須 | 説明 |
|---|---|---|---|
| `year_month` | `YYYY-MM` | ○ | 対象年月。ゼロ埋め必須（例: `2026-01`） |
| `amount` | 整数（円） | ○ | 金額 |
| `usage` | 数値 | △ | 使用量。単位はカテゴリごとに`categories.json`で管理。該当しないカテゴリは空欄 |
| `memo` | 文字列 | - | 備考 |
| `input_method` | `manual` / `ocr` / `api` / `ai` | ○ | 登録経路の記録 |
| `registered_at` | ISO8601 | ○ | 実際に登録された日時 |

- 文字コード: UTF-8（BOM付き、Excelでの文字化け防止）
- 同一`year_month`の再登録は「上書き」される（重複行にはならない）
- `data/categories.json` にカテゴリのメタ情報（表示名・単位・使用量の有無・色・表示順）を集約している

## カテゴリの追加方法

詳細は `README.md` を参照してください。手入力タイプのカテゴリは `data/<id>.csv` の作成と `categories.json` へのエントリ追加だけで、コードの変更なしに追加できます。
